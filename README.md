# IELTS 7.0 — خطة ومدرّب (A→Z Prep Manager + Grammar Trainer)

تطبيق محلي (**offline-first**) لمستخدم واحد (أحمد) يدير تحضير **IELTS Academic (فبراير 2027، هدف 7.0 في كل مهارة)** من البداية للنهاية: خطة مرحلية بجدول يومي، تسجيل نتائج الاختبارات والمقالات وجلسات المحادثة، باندات كل مهارة مع **الهامش عن 7.0** والاتجاه والتوقّع، وتقييم كتابة/تقرير أسبوعي بالذكاء الاصطناعي — فوق محرّك تمارين القواعد والنطق الأصلي (١٥ دقيقة يوميًا، «فكّر قبل أن تكشف»).

> **صفر تكلفة، لا خادم، لا حساب.** يعمل في المتصفّح (والإنترنت مطفأ) عدا ميزات الذكاء الاصطناعي. التمارين كلها حتمية قائمة على قواعد. الذكاء الاصطناعي يعمل بطريقتين: **مفتاح Claude API (للنصوص) و/أو مفتاح Gemini المجاني (يلزم للصوت) تلصقه مرة على كل جهاز** — يبقى على جهازك ولا يُرفع للمستودع ولا للمزامنة — أو، بلا أي مفتاح، **نسخ برومبت جاهز إلى Claude ولصق الردّ في التطبيق** (يقرأه تلقائيًا). راجع قسم «الذكاء الاصطناعي» أدناه.

## كيف تشغّله

**على الكمبيوتر (الأسهل):** اضغط ضغطًا مزدوجًا على `index.html` — يفتح في المتصفّح ويعمل فورًا دون إنترنت ودون خادم.

> بيانات التمارين مكتوبة كملفّات JSON ملفوفة بسطر JS واحد (`window.BANK_... = [...]`) تحديدًا لتعمل بالنقر المزدوج بلا خادم.

### على الأندرويد والآيباد

**الطريقة ١ — عبر الواي-فاي المنزلي (بدون أي نشر):**
1. على الكمبيوتر: شغّل `start-server.bat` (نقرة مزدوجة). سيطبع لك عنوانًا مثل `http://192.168.1.5:8123`.
2. على الموبايل/الآيباد (نفس الشبكة): افتح هذا العنوان في Chrome أو Safari.
3. اترك نافذة الخادم مفتوحة أثناء التمرين.
> بهذه الطريقة يعمل التطبيق كاملًا، لكن **التثبيت على الشاشة الرئيسية والعمل أوفلاين** يتطلبان HTTPS — أي الطريقة ٢.

**الطريقة ٢ — GitHub Pages (مرة واحدة، ثم يعمل أوفلاين للأبد):**
انشر المجلد على GitHub Pages (مستودعك جاهز). بعدها من الموبايل/الآيباد افتح الرابط ثم:
- **أندرويد (Chrome):** قائمة ⋮ ← «إضافة إلى الشاشة الرئيسية» ← يتثبّت كتطبيق ويعمل أوفلاين.
- **آيباد (Safari):** زر المشاركة ⬆ ← «Add to Home Screen» ← يتثبّت ويعمل أوفلاين.

بعد التثبيت لا يحتاج الجهاز الإنترنت إطلاقًا — الـ service worker يخزّن كل شيء.

> **ملاحظة:** التقدّم (`localStorage`) لكل جهاز على حدة. لنقله يدويًا: «البيانات» ← **تصدير/استيراد** — أو الأفضل: فعّل **المزامنة التلقائية** أدناه.

## المزامنة التلقائية بين الأجهزة (مجانية)

تعمل عبر **GitHub Gist سرّي** على حسابك — صفر تكلفة، لا خادم، لا اشتراك:

- بعد كل إجابة يُرفع تقدّمك تلقائيًا (بعد ٤ ثوانٍ من آخر تغيير).
- عند فتح التطبيق على أي جهاز يُسحب التقدّم ويُدمج.
- **الدمج ذكي**: اتحاد سجلّي الجهازين وإعادة حساب الإحصائيات — لو تدرّبت على الموبايل والكمبيوتر بالتناوب، لا يضيع شيء من أي منهما.
- دون إنترنت؟ يشتغل عاديًا ويُزامن تلقائيًا عند عودة الاتصال.

**التفعيل (مرة واحدة على كل جهاز):**
1. أنشئ توكن من [github.com/settings/tokens](https://github.com/settings/tokens) ← *Generate new token (classic)* ← علّم صلاحية **gist فقط**.
2. في التطبيق: «البيانات» ← «المزامنة التلقائية» ← الصق التوكن ← **تفعيل**.
3. كرّر الخطوة ٢ بنفس التوكن على بقية أجهزتك — سيجد نفس الـ Gist ويكمل عليه.

> التوكن يُخزَّن محليًا على جهازك فقط. الـ Gist «سرّي» (لا يظهر في بحث GitHub)، ويحوي فقط إجاباتك وأسبابك — لا بيانات حساسة.

التقدّم وسجل الأسباب يُحفظان في `localStorage` بالمتصفّح على جهازك. استخدم زر **«تصدير»** في تبويب «البيانات» لأخذ نسخة احتياطية `.json` أو لمشاركة سجلّ تفكيرك مع مدرّبك.

## مدير الخطة (A→Z) — ما الذي يفعله التطبيق لك

**الخطة** كلها في `data/plan.js` (ملف بيانات — عدّله بحرّية): المراحل (الخطة بدأت **٧ نوفمبر ٢٠٢٦ = اليوم ١** بقرار أحمد → تشخيص ٨–١٤ نوفمبر → بناء → حفاظ (يناير) → وضع الامتحان من ١ فبراير → ما بعد النتيجة → CMA)، الجدول اليومي لكل مرحلة (الكتلة الثابتة: نطق ٢٠ + مفردات ١٥ + جلسة قواعد، ومهارة اليوم)، أهداف الأسبوع (اختبارات/مقالات/جلسات)، قاعدة القرار بعد التشخيص، جداول تحويل الدرجة الخام → باند، قائمة المراجعة قبل التسليم، والمصادر.

## الذكاء الاصطناعي داخل التطبيق

0. **Claude API (للنصوص — يُخصم من رصيد حسابك):** [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys) ← Create Key ← الصقه (يبدأ بـ `sk-ant-`) في «الخطة» ▸ الذكاء الاصطناعي، **أو مباشرة في المكان الذي ضغطت فيه زر الذكاء** — كل زر AI بلا مفتاح يفتح نموذج المفتاح في مكانه ثم يكمل طلبك. يتولّى Claude نقاش الأخطاء، المدرّب العائم 🤖، تقييم الكتابة ونصّ المحادثة، والتقرير. النموذج الافتراضي `claude-opus-5-5` (قابل للتغيير إلى Sonnet 5.5 / Haiku 5.5 / Fable 5.1). التطبيق يستدعي Messages API مباشرة من المتصفّح (`fetch` + ترويسة `anthropic-dangerous-direct-browser-access` لأن التطبيق ملفات ثابتة بلا خادم ولا خطوة بناء؛ المفتاح على جهازك فقط). عند تفعيل المفتاحين: النصوص عبر Claude افتراضيًا (قابل للتبديل)، والصوت عبر Gemini دائمًا لأن Claude لا يسمع الصوت.
1. **Gemini (مجاني):** [aistudio.google.com/app/apikey](https://aistudio.google.com/app/apikey) ← Create API key ← الصقه في «الخطة» ▸ الذكاء الاصطناعي ← «اختبر وفعّل». يُنصح بتقييد المفتاح (Websites) بعنوان التطبيق. المفتاح يُخزَّن في `localStorage` منفصلًا عن بيانات التقدّم (لا يدخل التصدير ولا Gist المزامنة ولا المستودع). عند التقييم تُرسل المقالة إلى Google؛ في الطبقة المجانية قد تُستخدم البيانات لتحسين منتجاتهم.
2. **بلا إرسال (Claude ضمن اشتراكك):** في كل شاشة زر «انسخ برومبت لـ Claude» ← الصق في Claude ← انسخ ردّه كاملًا ← الصقه في صندوق «الصق ردّ Claude» ← «اقرأ الردّ». الردّ يحوي كتلة بين `<<<IELTS_JSON` و`IELTS_JSON>>>` يقرأها التطبيق.
3. **يدوي:** أدخل الدرجات من مدرّسك مباشرة.
4. **ناقش خطأك مع Claude أو Gemini داخل الصفحة (كتابة أو صوت):** بعد أي إجابة خاطئة في التمارين (وفي سجل الأخطاء القديمة) يفتح حوار سقراطي حيّ يبدأ من *تفكيرك المكتوب*، سؤالًا بسؤال حتى الفهم ثم ثلاثة أمثلة جديدة. 🎙 الإملاء الصوتي (عربي/English) وقراءة الردود بصوت عالٍ (الجزء العربي بصوت عربي والأمثلة الإنجليزية بصوت إنجليزي) عبر خدمات المتصفّح نفسه — الإملاء يعمل في Chrome/Edge/أندرويد عبر HTTPS؛ وضع 🎧 «متواصل» يرسل بعد كلامك ويستمع بعد الردّ. لا يُسجَّل صوت ولا يُقيَّم نطق. الحوارات تُحفظ في «سجّل نتيجة ▸ السجل» لمراجعتها مع مدرّبك.

## القراءة والاستماع داخل التطبيق («📖 اقرأ واسمع»)

- **القراءة:** نص + أسئلة بأنواع الامتحان (TRUE/FALSE/NOT GIVEN، اختيار من متعدد، إكمال بكلمات من النص، مطابقة العناوين، «في أي فقرة؟»)، مؤقّت (٢٠ د للنص، ٦٠ د للامتحان الكامل من ٣ نصوص)، تصحيح فوري، تقدير الباند، **«📍 أين الإجابة؟»** يظلّل الدليل في النص، وزر **«💬 اشرح لي خطأي»** لكل سؤال خاطئ.
- **الاستماع:** النص يقرؤه صوت المتصفح (بلا إنترنت ولا تكلفة؛ جودته حسب جهازك — اختر الصوتين من الشاشة نفسها). وضع الامتحان: يُسمَع مرة واحدة والأقسام الأربعة تتتابع؛ وضع التدريب: إعادة وتغيير سرعة. بعد التصحيح يظهر نص التسجيل مع تظليل الدليل. الصوت اصطناعي للتدرّب على الفهم — الامتحان الحقيقي بأصوات بشرية.
- كل نتيجة تُحفظ تلقائيًا في «التقدّم» (مصدر `in-app`) مع **أنواع الأخطاء**، وتُنجَز بها مهمة اليوم المقابلة وتُحتسب في أهداف الأسبوع.

## الفكرة الأساسية — «فكّر قبل أن تكشف»

لكل تمرين:
1. تظهر جملة بها فراغ (أو خيار متشابه).
2. تختار إجابتك.
3. **يجب** أن تكتب سببًا من سطر واحد («لماذا هذه الإجابة؟») قبل ظهور الحل.
4. عندها فقط تُكشف الإجابة الصحيحة + شرح مختصر + علامة صح/خطأ.
5. تُخزَّن **إجابتك وسببك** معًا لمراجعتهما لاحقًا (أنت ومدرّبك) في تبويب «البيانات».

لا يوجد اختصار لتخطّي كتابة السبب — بالتصميم.

## القواعد المُتتبَّعة (كلٌّ على حدة، بلا دمج للدرجات)

**القواعد (أنماط الخطأ الأربعة الأساسية):**
1. **الأدوات** — a / an / the / بدون أداة. مع تركيز على: «I have a car»، «advice» غير معدودة (لا «an advice»)، وقاعدة `of + اسم ⟵ the`.
2. **صيغة الفعل** — بعد حروف الجر (gerund) وبعد ضمائر الوصل (التطابق).
3. **الرابط والتطابق** — حذف is/are، و«the company **has**» لا «have».
4. **مفردات معكوسة المعنى** — قائمة قابلة للتوسعة (تبدأ بـ employer/employee).

**الصوتيات (طبقة المعرفة — تمارين اختيار؛ النطق الفعلي في شاشة «تكلّم» أدناه):**
5. **نبر الكلمة** · 6. **نبر الجملة** · 7. **رموز IPA** · 8. **الشوا /ə/**
9. **المتلازمات اللفظية** (Lexical Resource) — مستخرجة ومنسّقة من *Cambridge English Collocations in Use*.

## «تكلّم» — مختبر النطق وامتحان المحادثة (Gemini يسمعك)

منذ 2026-10-28 يغني التطبيق عن ELSA بقرار أحمد: تسجّل صوتك ويستمع إليه Gemini فعلًا.

- **مختبر النطق** (`js/pron.js` + `data/pron_units.js`): ١٥ وحدة للأصوات التي يتعثّر فيها متحدث العربية (p/b، f/v، θ، ð، ŋ، تجمّعات الحروف، /ɪ/–/iː/، /e/–/æ/، /æ/–/ʌ/، /ɜː/، /ɒ/–/ɔː/–/əʊ/، الشوا، النبر، التنغيم، الربط). كل جولة ٨ تمارين (أزواج متشابهة + كلمات + جمل): استمع (عادي/بطيء) ← سجّل ← درجة 0–100، كل كلمة ملوّنة بدرجتها، درجة الصوت المستهدف، «ماذا سمعتُ»، ونصيحة جسدية بالعربي. الكلمات الضعيفة تدخل «كلماتي للمراجعة» وتخرج عند إتقانها (٨٥+). تمرين اليوم المقترح = أول وحدة لم تُجرَّب ثم الأضعف.
- **امتحان Speaking محاكى** (`js/speak.js` + `data/speaking_qbank.js` + `data/speaking_cards.js`): Part 1 / Part 2 (دقيقة تحضير + دقيقتان) / Part 3 / كامل. الممتحن يقرأ السؤال بصوت عالٍ، يُقيَّم كل جزء بطلب واحد (الصوت + الأسئلة): المعايير الأربعة **بما فيها النطق من التسجيل**، نص حرفي لما قلته، كلمات النطق الخاطئة، أخطاء موسومة، وإجابة نموذجية Band 7.5 بأفكارك. النتيجة تدخل باند Speaking في «التقدّم» (`kind: "ai-audio"`) — تقييم مدرّب italki يبقى الأدق.
- **التسجيل** (`js/recorder.js`): Web Audio → WAV أحادي 16 كيلوهرتز (يعمل على Chrome/Edge/أندرويد/Safari؛ يحتاج https). **الصوت لا يُحفظ** — يُرسل إلى Google للتقييم ثم يُحفظ التقييم فقط.
- بعد تمارين نبر الكلمة/الجملة يظهر زر «🎙 انطقها الآن» لتقييم النبر فورًا.
- الدقة: Gemini أقل دقة من مقيّم متخصص في الأصوات المفردة، لكنه يلتقط أخطاء المتحدث العربي الشائعة بوضوح، ويضيف ما لا يقدّمه ELSA: باند IELTS، النص المكتوب، وربط كل شيء بخطتك.

التطبيق مبني كرفيق تدريب **طويل المدى (١٢+ شهر)** على خريطة من ٦ مراحل (`data/roadmap.js`):

1. أساسيات القواعد (مغلقة — هشّة تحت الضغط) → 2. الجمل المركّبة بالروابط (نشطة) → 3. المتلازمات (نشطة) → 4. بناء الفقرة → 5. مقالات كاملة تحت ضغط الوقت → 6. تثبيت باند ٧.

- **ثلاثة أوضاع تدريب**: القواعد **النشطة** تأخذ ~٧٠٪ من الجلسة، **الصيانة** (المغلقة) ~٢٠٪ كي لا تتآكل بصمت، **الخلفية** (الأدوات) ~١٠٪.
- **جلسة تحت الضغط ⚡**: مجموعة مؤقّتة بعدّاد تنازلي تخلط قواعد جديدة مع قواعد قديمة مغلقة في نفس الجلسة — لأن أخطاء المرحلة ١ تعود عندما ينتقل الانتباه لمحتوى جديد. نتائجها تُتتبَّع **منفصلة** عن الجلسات الهادئة.
- **بوابات الإغلاق**: لكل قاعدة معيار (افتراضيًا ≥٩٠٪ عبر ≥٣ جلسات ضغط في ≥يومين مختلفين — قابل للتعديل في `roadmap.js`). التطبيق **يقترح** عندما تبدو البوابة محقّقة؛ القرار لك مع مدرّبك — **لا تقدّم تلقائي أبدًا**.
- **جدولة Leitner**: كل عنصر في صندوق (١–٥)؛ صح ⟵ يصعد ويعود بعد فترة أطول (١/٣/٧/١٤ يومًا)، خطأ ⟵ يرجع للصندوق ١.
- **إنذار القواعد الهشّة**: قاعدة صيانة تهبط تحت ٨٠٪ تظهر في الرئيسية فورًا.

## الميزات

- **جلسة ١٥ دقيقة** — مجموعة مختلطة: Leitner + أوزان الأوضاع الثلاثة + أضعف قواعدك تحصل على أكثر.
- **تدرّب على قاعدة واحدة** — عناصر من قاعدة بعينها.
- **لوحة التقدّم** — لكل قاعدة على حدة: دقّة % · **هادئ مقابل تحت الضغط** (مع تنبيه «ينهار تحت الضغط» عند فجوة ≥١٥٪) · محاولات · ستريك · مخطّط بصري. بلا «درجة إجمالية» مدموجة.
- **مولّد مواضيع Task 2** — مواضيع عامة فقط (تعليم/بيئة/تقنية/صحة/مجتمع/ثقافة) — **بلا مالية عمدًا** كي لا تتضخّم Lexical Resource بمفرداتك التخصصية.
- **قاموس النطق الشخصي** — بطاقات (word · IPA · تقريب عربي · نمط النبر · سياق مالي)، قابلة للإضافة يدويًا.
- **مرجع المتلازمات** — قائمة بحث + إضافة أزواج كلمات متشابهة (تدخل الدرّيلات فورًا).
- **رسوم توضيحية** — مخطّطات SVG أوفلاين لكل قاعدة.
- **فحص الكتابة** — الصق مقالك ⟵ يولّد **برومبت تقييم كامل** (٤ معايير + وسم كل خطأ بأحد الأنماط الأربعة + كشف تضخّم Lexical Resource بسبب مفردات المال) تنسخه وتلصقه في Claude.
- **الترجمة** — حدّد أي نص إنجليزي داخل التطبيق واضغط **«ترجم المحدد»** (زر عائم)، أو الصق النص ⟵ يولّد برومبت ترجمة تلصقه في Claude. ومن الشاشة نفسها زر **«محتوى مرئي»** يولّد برومبت لإنشاء صورة/مخطّط تعليمي.

## أين تعيش البيانات وكيف تضيف

| ماذا | الملف | كيف تضيف |
|---|---|---|
| **خطة الامتحان** (مراحل، جدول يومي، أهداف، قرار التشخيص، جداول الباند، المصادر) | `data/plan.js` | عدّل التواريخ/المهام/الأهداف مباشرة — بلا كود |
| **نصوص القراءة** (١٢ نصًّا أصليًا × ١٣ سؤالًا = ١٥٦ سؤالًا، راجعها قارئ مستقل) | `data/reading.js` | `{id,title,pattern:A|B|C,paragraphs[],headings?,questions[]}`؛ كل سؤال له `evidence` نصّه حرفيًّا من النص ليظهر مظلَّلًا بعد التصحيح |
| **أقسام الاستماع** (٨ أقسام × ١٠ أسئلة، تُقرأ صوتيًا؛ الأرقام والرموز والتهجئة تُحوَّل لنطق صحيح) | `data/listening.js` | `{id,section:1-4,turns[{s:A|B|C,text}],questions[10]}` — يقرؤها صوت المتصفح (TTS) |
| **قواعد إضافية** (الأزمنة، الشرط، المجهول، الصلة، المعدود، الاشتقاق، الربط، حروف الجر) + تمرين **«اكتشف الخطأ»** | `data/grammar_more.js` (+ وحدة لكل قاعدة في `data/modules/`) | أضف عنصرًا في مصفوفة القاعدة. «اكتشف الخطأ»: `{sentence, words[], error_index, correction, explanation}` — تضغط الكلمة الخاطئة ثم تكتب السبب |
| **مفردات إضافية**: AWL القائمة ٣ (١٢١–١٨٠)، مفردات المواضيع (بيئة/تقنية/صحة/تعليم/مجتمع/مدن)، الأفعال المركّبة، لغة وصف الرسوم (Task 1)، متلازمات وأزواج إضافية | `data/vocab_more.js` | أضف عنصرًا في المصفوفة المناسبة؛ مهمة «مفردات اليوم» تخلطها كلها |
| مفردات AWL (بطاقات التمرين) | `data/vocab_awl.js` | أضف عنصرًا بنفس الشكل (`rule:"vocab_awl"`) — والكلمات من تقييمات الكتابة تُضاف من داخل التطبيق |
| بطاقات Speaking Part 2 | `data/speaking_cards.js` | أضف بطاقة `{id, topic, text, bullets[4]}` |
| مواضيع Task 1 (بيانات نصّية) | `data/writing_prompts.js` ← `WRITING_PROMPTS_T1` | `{id, type, text, data_rows[]}` والصفّ الأول عناوين الأعمدة |
| خريطة الطريق والبوابات | `data/roadmap.js` | عدّل المراحل/المعايير مباشرة |
| **وحدة قواعد جديدة** (connectors…) | `data/modules/` | انسخ أي وحدة + أضف اسم الملف في `_index.js` — **بلا أي تعديل كود** |
| تمارين القواعد (أدوات/فعل/رابط) | `data/grammar.js` | أضف عنصرًا للمصفوفة بنفس الشكل |
| أزواج المعنى المعكوس | `data/vocab.js` | أضف زوجًا، أو من داخل تبويب «المرجع» |
| صوتيات (نبر/IPA/شوا) | `data/phonetics.js` | حسب القسم |
| قاموس النطق | `data/pron_dict.js` | أو من داخل تبويب «القاموس» |
| المتلازمات + المرجع | `data/collocations.js` | أضف عنصر درّيل و/أو مدخل مرجع |
| مواضيع Task 2 | `data/writing_prompts.js` | أضف موضوعًا (عام — بلا مالية) |

**مثال: فتح وحدة connectors عند بدء تدريسها** — أنشئ `data/modules/connectors.js`:
```js
window.registerModule({
  module_id: "connectors", name_ar: "الروابط", name_en: "Connectors",
  stage_id: 2, mode: "active",
  rules: [{ id:"connectors", label:"الجمل المركّبة بالروابط", group:"القواعد", short:"روابط" }],
  items: [ { id:"con-1", rule:"connectors",
             sentence_with_gap:"___ it was raining, we went out.", correct_answer:"Although",
             distractors:["Because","If","When"], explanation:"تناقض بين العبارتين ⇒ Although." } ]
});
```
ثم أضف `"connectors.js"` إلى القائمة في `data/modules/_index.js`. انتهى.

كل ملفّ في `data/` مشروح بأعلاه بالشكل المطلوب لكل عنصر. مثال عنصر قاعدة:
```js
{ id:"art-99", rule:"articles",
  sentence_with_gap:"I need ___ pen.", correct_answer:"a",
  distractors:["an","the","(no article)"],
  explanation:"مفرد معدود غير محدّد ⇒ a." }
```
الإنجليزية تبقى LTR، والشرح عربي (RTL).

## البنية

```
index.html            ← يحمّل كل شيء بالترتيب
css/styles.css        ← RTL عربي + جزر LTR للإنجليزية، موبايل أولًا
data/                 ← المحتوى (لا يلمسه الكود أبدًا — «فصل المحرك عن المحتوى»)
  plan.js             ← خطة الامتحان: المراحل، الجدول اليومي، الأهداف، قرار التشخيص، جداول الباند، المصادر
  vocab_awl.js        ← بطاقات Academic Word List (وحدة vocab_awl)
  speaking_cards.js   ← بطاقات Part 2
  roadmap.js          ← المراحل الست + معايير البوابات
  writing_prompts.js  ← بنك مواضيع Task 2 (عامة فقط) + Task 1 (بيانات نصّية)
  modules/_index.js   ← قائمة الوحدات — أضف اسم ملف لفتح وحدة جديدة
  modules/*.js        ← وحدة لكل قاعدة: {module_id, stage_id, mode, rules, items}
  grammar|vocab|phonetics|collocations|pron_dict.js  ← بنوك العناصر
js/                   ← المحرك (لا يحتاج تعديلًا لإضافة محتوى)
  config.js           ← يبني سجلّ القواعد من الوحدات المسجّلة
  storage.js          ← localStorage: سجل كامل + Leitner + حالات المراحل + إعدادات
  sync.js             ← مزامنة تلقائية عبر GitHub Gist (دمج ذكي)
  engine.js           ← تركيب الجلسات (نشط/صيانة/خلفية) + جلسة الضغط + البوابات + الهشاشة (+ دفعة أخطاء الكتابة)
  plan.js             ← محرّك الخطة: المرحلة لأي تاريخ، مهام اليوم، الأسابيع، الدقائق المخطّطة، قرار التشخيص
  tracker.js          ← الباندات لكل مهارة، الهامش، الاتجاه، التوقّع، إحصاء الأسبوع، أخطاء الكتابة → دفعة التمرين
  ai.js               ← عميلا Claude (نصوص) وGemini (صوت + بديل) والتوجيه بينهما (المفاتيح على الجهاز فقط)
  drills.js           ← محرّك «فكّر قبل الكشف» + تذكير «اقرأها بصوت عالٍ»
  session.js          ← مشغّل الطابور + العدّاد التنازلي + الملخّص (مع المدة)
  diagrams.js         ← رسوم SVG لكل قاعدة
  dashboard.js        ← بطاقات الإحصاء (هادئ/ضغط) + مخطّطات SVG
  prompts.js          ← مولّدات البرومبت + عقود JSON المشتركة بين Claude وGemini ومسار اللصق + القارئ
  views_prep.js       ← شاشات الخطة: اليوم، الخطة، سجّل، الكتابة، التقدّم، التقرير، المزيد
  app.js              ← الراوتر + شاشات المحرّك (الخريطة، الضغط، القاموس، المرجع، البيانات…)
```

> **عند تعديل أي ملف — قبل الـ commit شغّل `node bump.js`:** يرفع `CACHE_VERSION` في `sw.js` ويختم كل روابط الملفات بـ `?v=N` (في `index.html` وقائمة `ASSETS` ومحمّل الوحدات). بدونه قد يخدم CDN الخاص بـ GitHub Pages (كاش ١٠ دقائق) أو التطبيق المثبَّت النسخة القديمة.

## خارج النطاق (لم يُبنَ عمدًا)

حفظ التسجيلات الصوتية (تُقيَّم ثم تُهمَل)، نسخ أسئلة Cambridge أو أي اختبار رسمي (المحتوى داخل التطبيق كله أصلي؛ الاختبارات الرسمية تُحلّ خارجه وتُسجَّل من «سجّل نتيجة»)، تعدّد مستخدمين، تسجيل دخول، خوادم خاصة، لوحات متصدّرين، أي مدفوعات داخل التطبيق (استدعاءات Claude API تُخصم من رصيد حسابك أنت باختيارك). عدّاد الستريك هو التلعيب الوحيد المسموح.
